# Agile User Stories
## Hospitality and Event Management System (HEMS)

### Epic 1: Event Lifecycle & Setup
- **US-01:** *As an Event Manager*, I want to create a new event with its date, guest count, and budget, *so that* I can formally establish the project scope.
  - **Acceptance Criteria:** Required fields validated; positive guest count and budget enforced; success confirmation shown upon creation.
- **US-02:** *As an Event Manager*, I want to review an executive dashboard of all ongoing events, *so that* I have real-time visibility over dates, statuses, and budget allocations.

### Epic 2: Intelligent Requirement Formulation
- **US-03:** *As an Event Manager*, I want the system to automatically analyze my event parameters and generate reasonable requirements, *so that* I do not have to manually brainstorm basic hospitality needs from scratch.
  - **Acceptance Criteria:** Generates Catering, Seating, AV, Decor, Photography, Logistics, and Hygiene items; estimates costs scaling to budget; assigns priorities.
- **US-04:** *As an Event Manager*, I want to edit, add, and delete generated requirements, *so that* I can customize the plan to match specific client needs.

### Epic 3: Operational Task Execution
- **US-05:** *As an Event Manager*, I want to assign tasks with due dates to committee members, *so that* milestones are clearly tracked.
- **US-06:** *As an Event Manager*, I want to update task statuses between Pending, In Progress, and Completed directly from the task list, *so that* team progress is updated without tedious clicks.

### Epic 4: Budget Governance & Expense Tracking
- **US-07:** *As an Event Manager*, I want to record actual expenses with supplier references and dates, *so that* our financial records are maintained accurately.
- **US-08:** *As an Event Manager*, I want an immediate warning alert if total expenses exceed the approved event budget, *so that* we can prevent deficit spending before it worsens.

### Epic 5: Supplier Engagements
- **US-09:** *As an Event Manager*, I want to browse a verified supplier catalog and review vendor ratings, *so that* I select reliable hospitality partners.
- **US-10:** *As an Event Manager*, I want to link a supplier and service to an event with agreed contract pricing, *so that* contractual commitments are formalized.
